# 嘉立创 PCB 设计

**[English](README.en.md)** · 中文

## 安装 Prompt（复制到 Agent）

```text
请把当前工作区里的 `skills/easyeda-pcb-design/` 安装为我可用的 Agent Skill。

要求：
1. 只安装 `skills/easyeda-pcb-design/`（入口为该目录下的 `SKILL.md`）。
2. 安装后确认技能名称可用，并告诉我以后该怎么唤起。
3. 不要改动 skill 里的业务规则与参考文档内容，除非安装本身必须做路径/配置调整。
4. 若环境还需要配套的 easyeda-api，请一并说明是否已就绪、缺什么。

安装完成后，用一句话说明：我下次如何让你用这个 skill 帮我设计或检查嘉立创 PCB。
```

## 这是什么

用 AI 在**嘉立创 EDA 专业版**里做原理图和 PCB：从普通板子到高速、阻抗相关设计，按步骤帮你画、改、检查。

## 你能用它做什么

- 画原理图、排布器件、布线、铺铜
- 处理射频模组自带 PCB 天线和主板板载天线的禁布、馈线、匹配与验证
- 做完后做一轮设计检查，减少漏项
- 只有在需要时才启用高速/阻抗相关指引，不把简单板子搞复杂

## 使用前提

- 已安装并打开**嘉立创 EDA 专业版**
- 已安装配套 **easyeda-api** skill，且本地 easyeda-bridge 可连（缺一不可；Agent 不得臆造 API）
- 你的 AI 工具支持安装本地 skill

**不适用：** KiCad / Altium / OrCAD 等非嘉立创 EDA 工程。

**重要：** 审计结果 **不是**下单打样授权。高速证据优先用磁盘 artifact；文字证据需**你本人**设置 `EASYEDA_AUDIT_USER_ATTEST=YES` 并手写 attest 文件（Agent 不得代写/代设）。基线会综合完整 PCB 网表、显式接口约束、差分形态和协议/RF 候选；未决信号会保持 `UNVERIFIED`。高速报告必须匹配当前工程、PCB、设计/约束指纹并覆盖全部候选网。晶振/时钟网则需单独的晶振专项审计报告。

## 装好后怎么用

直接说你的板子需求即可，例如：

- 「用嘉立创 PCB 设计 skill，帮我做一款 STM32 最小系统」
- 「检查一下当前这块板，看有没有明显问题」
- 「这块有 USB 高速信号，按需要启用相关检查」
